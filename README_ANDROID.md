# KemRPhelper v1.6 — Android

Порт KemRPhelper на Android с плавающим оверлеем поверх игры, копированием фраз в 1 тап, редактированием фраз, всеми 7 фракциями и шпаргалкой по УК/КоАП РФ.

## Как собрать готовый APK через GitHub (без Android Studio)

1. Создай новый репозиторий на GitHub (например, `KRP_Helper_Android`) или отдельную ветку `android` в текущем репозитории.
2. Залей туда все файлы из этого архива (важно, чтобы папка `.github/workflows/build-apk.yml` оказалась в корне репозитория!).
3. Открой вкладку **Actions** на GitHub → выбери запущенный workflow **Build KemRPhelper Android APK**.
4. Через ~2 минуты внизу страницы появится раздел **Artifacts** → скачай `KemRPhelper-v1.6-APK`.
5. Распакуй архив на телефоне и установи `KemRPhelper-v1.6.apk`.

## Использование в игре

1. Открой приложение, выбери свою фракцию, впиши звание и фамилию.
2. Нажми **«ЗАПУСТИТЬ ОВЕРЛЕЙ ПОВЕРХ ИГРЫ»** и выдай разрешение «Поверх других приложений».
3. Заходи в игру — поверх экрана будет висеть плавающий кружок `RP` (его можно перетаскивать куда угодно).
4. Тап по кружку открывает панель фраз и статей. Нажатие на любую фразу копирует её в буфер обмена и сворачивает панель — остаётся нажать «Вставить» на клавиатуре в чате.
